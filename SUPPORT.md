# Support

For help using OpenFi, search [existing issues](https://github.com/wpfyorg/OpenFi/issues) first. If you do not find an answer, [open an issue](https://github.com/wpfyorg/OpenFi/issues/new/choose) with the **Support question** template.

Include the OpenFi version or commit, relevant OpenWrt and runtime versions, what you expected, what happened, and safe reproduction steps. Prefer mock mode (`cargo run -- --mock fixtures --listen 127.0.0.1:8088`) when demonstrating behavior.

Before posting, remove passwords, tokens, session cookies, Wi-Fi keys, public IP addresses, MAC addresses, serial numbers, hostnames, and other private network or device details from logs and screenshots. Do not use public issues for security reports; see [SECURITY.md](SECURITY.md).

This project is maintained on a best-effort basis. A support request does not guarantee a response or resolution time.
