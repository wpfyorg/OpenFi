# Security policy

Please report security vulnerabilities privately. Do not disclose an unpatched vulnerability in a public issue, discussion, or pull request.

## Reporting

When enabled, use GitHub's **Report a vulnerability** option in the repository's **Security** tab to send a private vulnerability report. If that option is unavailable, check the maintainer's [GitHub profile](https://github.com/wpfyorg) for a published private contact method. GitHub profiles do not provide direct messaging. If no private method is published, request that private reporting be enabled without posting vulnerability details.

Include enough detail to reproduce and assess the issue:

- Affected version or commit and relevant environment, with device and network identifiers removed.
- Impact and the conditions needed to trigger the issue.
- Minimal reproduction steps, sanitized requests or logs, and any suggested mitigation.

Remove passwords, session cookies, API keys, Wi-Fi keys, public IPs, MAC addresses, serial numbers, and other identifying or access-bearing data. Do not attach an unredacted configuration or packet capture. There is no published response-time commitment; avoid sharing details publicly while the issue is under review.

## Scope

Reports about vulnerabilities in this repository or its supported deployment are welcome. Security reports are reviewed by the maintainers; filing a report does not imply a particular severity or resolution timeline.
